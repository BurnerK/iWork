# ADR-0004: 使用 HarnessAgent 恢复和压缩会话上下文

**日期**: 2026-11-16

**状态**: 已接受

**决策者**: Eren <burnerk@foxmail.com>

## 背景

用户需要在长会话中连续工作，并在重启后基于已保存内容发起新任务。作出决定时，已有原型验证了 ReActAgent 的部分运行行为，正式运行模块尚未定型。

## 决策

主应用采用 AgentScope Java 2.0.4 HarnessAgent，显式启用上下文持久化和自动压缩。完整消息、上下文快照及摘要存入 MySQL，按用户和会话隔离并关联来源任务。iWork 在每次新任务中重新校验权限，只开放已授权的固定业务工具。

## 考虑的备选方案

### 备选方案 1: 先实现 ReActAgent，再迁移到 Harness

ReActAgent 能调用工具并持久化 AgentState，已有探针可供参考。但这条路径需要先建设专用上下文管理，再迁移到已选定的 Harness。

## 影响

### 积极影响

新任务可复用历史上下文。压缩保留完整业务消息和成果，便于核对快照或按业务记录重建。

### 消极影响

摘要和溢出恢复会增加模型调用、费用及失败路径，均须按次授权和计量。[ADR-0003](0003-estimated-usage-for-internal-quotas.md)

### 风险

恢复快照可能带回旧权限或未完成的工具操作。禁用待执行工具恢复、通用文件与 shell/Web 工具、长期记忆、动态 Skill/MCP、子智能体、Plan Mode 和独立会话日志及卸载。快照不一致时核对业务历史；压缩失败且原上下文超出预算时明确失败。SDK 开关需在锁定版本上验证，真实模型压缩后的交流质量另行验收。[上下文任务](https://github.com/BurnerK/iWork/issues/27)
