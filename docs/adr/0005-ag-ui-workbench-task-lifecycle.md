# ADR-0005: 工作台通过 AG-UI 提交和查看后台任务

**日期**: 2026-11-19

**状态**: 已接受

**决策者**: Eren <burnerk@foxmail.com>

## 背景

生成文档可能持续到用户关闭页面之后。用户刷新页面或在第二个标签页打开会话时，需要看到同一次任务已经生成的回复，并继续接收更新。

## 决策

Vue 工作台通过 AG-UI 提交请求，后端决定立即执行或排队。刷新和重连按已有任务 ID 恢复查看，先显示已生成正文，再接上增量。关闭页面只结束本次查看，用户可单独发起取消。工作台显示真实工具进度，解析失败时指出具体资料，文档成功后自动保存并提供打开指定版本的成果卡片。

## 考虑的备选方案

### 备选方案 1: 通过自然语言指令打开预览

用户可以直接在对话中要求打开文档，但需额外支持触发前端预览的工具。2026-11-20 取消这项需求，保留成果卡片入口。[取消记录 #49](https://github.com/BurnerK/iWork/issues/49)

### 备选方案 2: 首版接入人工审批

审批可以让用户决定是否执行特定操作。2026-11-20 决定等有明确需要批准的操作时再接入。

## 影响

### 积极影响

用户离开页面后任务仍可完成；回到会话时，原成果卡片仍能打开对应版本。

### 消极影响

工作台要分别管理提交、订阅和恢复，并衔接完整正文与后续增量。

### 风险

把重连当作新请求会重复执行或生成多个版本；重复追加快照也会让正文重复。验收时覆盖生成中刷新，以及两个页面同时查看同一文档任务。
