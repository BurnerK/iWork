# 工作台通过 AG-UI 查看独立执行的任务

2026-11-19 确认。首版以 iWork 自带的 Vue 工作台验收 AG-UI：用户在会话中提交消息后，能逐段看到回复，并能区分任务成功与失败。

任务执行由后端管理。关闭页面或断线只结束本次查看，任务继续执行；用户回到会话时，工作台恢复查看同一次任务的进度或结果。用户可以显式取消任务。这样，生成文档等耗时工作可以跨越一次页面访问，重新查看也不会重复执行。

用户在生成途中刷新页面时，工作台直接显示该回复已经生成的完整正文，再接上后续文字。已生成的文字只显示一次。

工作台通过 AG-UI 提交新的工作请求，由现有任务系统决定立即执行或排队。刷新、重连或从第二个标签页查看时，工作台按已有任务 ID 恢复查看。两个页面查看同一次文档生成任务时，后台只执行一次，只生成一个成果版本。

首版还验收以下交互：

- 工作台展示真实工具进度，资料处理失败时指明对应资料。文档生成成功后自动保存为正式版本，工作台显示成果卡片，刷新后仍能打开同一版本。
- 用户要求打开刚生成的文档时，智能体通过前端工具请求 Vue 工作台打开指定版本的预览。

2026-11-20 确认将人工审批推迟到后续版本，等有具体操作需要用户批准时再接入。
