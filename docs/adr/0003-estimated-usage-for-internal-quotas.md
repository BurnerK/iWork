# 缺失用量按调用估算内部额度

2026-11-12 确认：供应商返回有效用量时按回报核算内部额度；缺少完整回报时，根据可观察的输入与输出估算，明确记录估算来源。以每次模型调用为单位分别记录，不能因任务内已有其他调用的有效用量就跳过缺失调用。执行收尾后释放额度预占，不因供应商实际用量未知而长期冻结额度。

估算仅用于内部额度核算，供应商实际消耗仍保留“用量待核实”，不得将估算冒充最终账单或把缺失用量自动置零。这延续 [原型收口决议 #7](https://github.com/BurnerK/iWork/issues/7#issuecomment-6821251509) 的证据边界。首版接受内部额度与供应商实际费用可能存在差额，以避免少量内部用户因未知用量长期无法使用额度。

本轮曾考虑在未知用量核实前持续保留预占，最终选择估算后释放。预占金额算法、无法可靠估算的处理、后续证据到达时的差额调整与审计细则留待计量设计；不将该决定解释为已经完成供应商对账或保证绝不超出真实费用预算。
