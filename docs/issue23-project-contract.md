# #23 个人项目空间边界

项目是当前用户的组织入口，不是新的所有者、共享知识库或自动检索范围。项目保存名称与可选的最多 4000 字符指令；会话可归属于一个项目或独立存在。管理员也不能读取或修改别人的项目。

提交新任务时，事务在当前身份锁内读取项目和智能体配置。项目指令作为工作背景、智能体指令作为处理方式、本次用户要求优先，且不扩大工具或授权。任务保存提交时的配置；移动会话、编辑或删除项目只影响后续新任务。同请求标识的重试返回原任务，不重新读取配置或重复执行。会话上下文仍按原 owner/conversation 保存，项目不改变摘要来源和恢复边界。

项目资料引用指向个人原文；任务仍须明确选择至多五份资料，项目引用本身不授权读取其他资料。项目成果引用指向同一 document，包含其所有正式版本；项目中任务发布成果时在成果提交事务内添加引用。用户可引用已有版本、预览、下载并在项目新会话中明确提交修订。跨项目修订延续原 document 的版本号和个人所有者。

`/api/projects` 提供个人分页查询和创建，`/{id}` 提供查询、更新、删除。`/{id}/conversations`、`materials`、`documents` 按每页 20 项查询；后两者支持添加和移除引用。`PUT /api/conversations/{id}/project` 接收项目 ID 或 null。所有读写验证当前用户所有权，写入重新验证身份，外部 ID 不作为授权依据。

删除项目使用原生确认对话框，只删除项目和引用，通过外键将会话与任务的项目关联置空；原始资料、正式成果、版本、会话及任务记录保留。删除不取消已受理任务；若其成果稍后发布，仍保存于个人会话与成果列表。移除单条引用同样不删除原文或版本。移动会话保留未提交草稿和资料选择。
