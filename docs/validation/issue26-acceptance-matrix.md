## 每位参与者独立完成

1. 登录自己的账号，直接选择获授权模型，上传获准资料并明确选定，提交文档要求。记录任务ID、资料范围、实际工具调用、正式成果/版本ID，检查可读性、要求完成情况、引用资料准确性，下载旧版。
2. 保存个人智能体的处理指令和模型，再提交代表任务；在项目中保存背景指令并组织会话/资料/成果。明确选择资料，核对实际输出与所选配置一致。另用独立会话，保留来源与归属。
3. 提交后关闭网页，再登录或打开页面找到同一任务，不产生重复任务或重复计量。检查后台完成、正式预览和下载。
4. 隔天找回同一成果，在原会话及代表性的另一项目中基于明确来源版本续改；记录新版本，核对旧版下载字节未改。未真实跨日不能标通过。
5. 进行足够长的真实交流，实际触发Harness摘要；继续问工作背景并修改文档。参与者评估背景遗漏/幻觉、正文质量和完整历史保留；诊断中核对SUMMARY与MAIN及可能OVERFLOW的独立用量。
6. 在批准预算内做一项取消/故障代表流程，核对业务状态、本地执行、供应商响应/用量待核实、资料清理各自结果。不能以本地取消宣称供应商零消耗、停止或结清。
7. 由管理员验证实际用户的模型权限/额度生效和受限诊断；对其他用户的正文、资料、成果、快照不默认可读。记录问题及修复后必要复验。
