# #16 资料解析与容器监督合同

支持 #15 已接收的 TXT/Markdown，使用 Python 3.13.18 标准库严格 UTF-8（允许 BOM）解码、统一换行；保留 Markdown 原文，不执行标记、链接或代码。输入上限 2 MiB，解析文本上限 2 MiB；模型读取每次最多 12,000 字符并支持显式偏移，任务页可查看解析状态。解析文本是任务材料，不是正式文档成果。

管理服务和看门狗复用主应用 Java 21 构建产物，以独立入口运行，不启动 Spring、不读取数据库配置；管理镜像增加锁定 Docker CLI。处理镜像固定 Python 3.13 Alpine 摘要（沿用已验证镜像），固定入口，无动态命令、路径、镜像或挂载参数。主应用仅通过内部 HTTP 接口访问管理服务，服务身份由本地生成的 256 位随机密钥文件分发到应用与管理服务，看门狗及处理容器均无密钥。逐处理任务另有随机令牌，管理记录只保存摘要；错误令牌与跨任务访问失败关闭。

管理服务持久保存处理 ID、业务任务关联、容器名/ID、状态和清理状态。写入创建意图后才创建容器。处理容器非 root、只读根、无网络、无宿主挂载、无能力、禁止提权，内存/交换总额 64 MiB、CPU 0.5、进程数 32；仅 4 MiB tmpfs。输入通过标准输入，输出有界。单实例最多 2 个处理任务。正常执行期限 30 秒，独立看门狗按 Docker Created 与固定实例标签执行 60 秒回收；心跳超过 2 秒拒绝新建。这些是首次运行的保守参数，不是生产 SLA，#25 需实机标定。

正常、失败、取消、超时均强制删除后用独立 Docker 查询确认不存在。无法确认保留 UNKNOWN、持续重试并禁止新建。管理服务重启先核对自身实例遗留容器再接收新建，不自动重跑解析。Docker/宿主不可用不能保证墙钟停止期限。

Harness 显式串行执行工具，只注册固定资料解析/有界读取工具，按当前调用用户、运行任务和 task_materials 快照重新授权，不向模型提供管理凭据或任意路径。结果写入 MySQL 前锁定业务任务，终态后不发布迟到结果。应用重启不自动重跑，管理服务与看门狗负责余下清理。任务页面把处理状态与容器清理状态分开显示。

验证覆盖真实 Docker/Compose、真实 MySQL/身份/文件存储，模型仅替换外部传输；新增解析、授权、取消、时限和独立删除证据。#21 扩展系统性故障注入；不把本地实测当作生产验收。
