# iWork 页面结构

## 站点入口与导航

iWork 使用 Vue Router 的 hash 路由。打开站点根路径会进入 `/#/conversations`。未登录时跳转到登录页，需要改密时进入改密页。非管理员打开管理页面时会返回个人会话。下表使用路由定义中的路径，浏览器地址会在路径前加上 `#`。[路由定义](../frontend/src/router.ts) · [页面外壳](../frontend/src/App.vue)

工作台由顶部栏、主导航和内容区组成。桌面端的会话页面还有可折叠的侧栏，提供新建会话、最近会话、分页和项目空间入口。窄屏通过顶部按钮打开导航对话框，在其中切换页面或打开最近会话。账号菜单提供修改密码和退出。

## 页面与路由

| 路由 | 页面 | 内容区 |
| --- | --- | --- |
| `/login` | 登录 | 账号、密码、密码显隐和登录结果。 |
| `/password` | 修改密码 | 当前密码、新密码和密码要求。首次改密也使用此页。 |
| `/conversations` | 个人会话首页 | 新会话欢迎区和任务输入区。首次任务确认受理后打开对应会话详情。 |
| `/conversations/:id` | 会话详情 | 项目归属、消息与任务、成果版本和任务输入区。 |
| `/projects` | 项目空间 | 项目列表、分页和新建表单。 |
| `/projects/:id` | 项目详情 | 项目设置、会话、引用资料、引用个人资源、正式成果和删除项目。 |
| `/agents` | 我的智能体 | 智能体列表、分页，以及页内新建和编辑表单。 |
| `/models` | 模型与额度 | 当前用户的可用模型、输入与输出计价，以及可用、总额、已用和预占额度。 |
| `/admin` | 用户管理 | 创建用户、展示临时密码、分页查看用户、启用或禁用普通用户、重置密码。 |
| `/admin-models` | 模型管理 | 实例币种、模型列表和编辑表单、用户模型授权与个人额度。 |
| `/admin-diagnostics` | 运行诊断 | 按任务 ID 查询、分页查看近期任务、在页内查看选中任务的诊断结果。 |

## 详情页结构

### 会话详情

顶部栏显示会话标题。内容区先提供可展开的「项目归属」，然后由 `TaskPanel` 组织消息区和输入区。

1. **消息区**按任务归组显示用户消息和助手回复。运行中的回复逐步更新，并显示工具进度。任务失败、暂停或取消时，消息旁显示对应状态和可用操作。
2. **任务详情**从对应消息下展开，可查看任务 ID，并打开用量、资料处理或运行诊断面板。
3. **成果入口**位于生成成果的那条回复中。点击成果卡片可预览指定版本，也可以通过「浏览文档版本」查看历史版本。
4. **输入区**包含工作要求、模型或智能体、资料与成果形式，以及提交按钮。存在待发送消息时会显示队列。用户续改文档时，输入区会显示所选来源版本。

[页面外壳](../frontend/src/App.vue) · [项目归属](../frontend/src/ProjectMembership.vue) · [任务面板](../frontend/src/TaskPanel.vue)

### 项目详情

项目名和设置表单位于内容区顶部。下面依次列出项目会话、项目引用资料、引用个人资源的表单和正式成果。用户可以打开已有会话、在项目中新建会话、下载原始资料或移除引用。项目引用资料需要在会话提交任务时明确选用。

在项目成果列表选择「基于此版本修改」会创建项目会话并打开 `/conversations/:id?version=<版本 ID>`，由会话输入区加载所选来源版本。删除项目通过页内确认对话框完成，会话、原始资料和正式成果仍保存在个人空间。[项目面板](../frontend/src/ProjectPanel.vue) · [文档面板](../frontend/src/DocumentPanel.vue)

## 页内详情组件

会话和项目详情有各自的路由。任务详情、成果预览和编辑表单由所在页面打开，入口和内容如下。

| 详情组件 | 从哪里打开 | 展示内容和操作 |
| --- | --- | --- |
| [`DocumentPanel`](../frontend/src/DocumentPanel.vue) | 会话中的成果卡片或版本列表、项目成果列表 | 会话用对话框展示标题、版本号和 Markdown 正文，可下载或基于该版本继续修改。项目在列表下展示只读预览。 |
| [`UsagePanel`](../frontend/src/UsagePanel.vue) | 会话任务详情的「查看用量」 | 展示每次模型调用的用量和计量状态。 |
| [`ParsingPanel`](../frontend/src/ParsingPanel.vue) | 会话任务详情的「资料处理」 | 展示各项资料的处理和清理状态，按段查看可读取的解析文本。 |
| [`DiagnosticsPanel`](../frontend/src/DiagnosticsPanel.vue) | 会话任务详情或管理员的运行诊断页 | 展示任务状态、上下文阶段、模型调用、资料处理与清理、成果发布。管理员可从近期任务列表选择，也可按任务 ID 查询。 |
| [`MaterialPanel`](../frontend/src/MaterialPanel.vue) | 任务输入区的「资料」 | 展示项目引用资料和个人资料供本次任务勾选。个人资料区提供上传入口。 |
| [`AgentPanel`](../frontend/src/AgentPanel.vue) | 「我的智能体」中的新建或编辑入口 | 在列表所在页面编辑名称、指令和模型。 |
| [`ModelPanel`](../frontend/src/ModelPanel.vue) | 「模型管理」中的添加或编辑入口 | 在管理页编辑模型配置；用户授权和额度也在同一页管理。 |

视觉规则见 [DESIGN.md](../DESIGN.md)。组件开发和无障碍要求见 [前端组件开发规范](COMPONENT-GUIDELINES.md)。
