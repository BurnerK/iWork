# iWork 产品范围

## 产品定位

iWork 面向个人和小规模内部团队。部署者提供一个由自己管理的 Web 应用，成员在各自账号下使用组织授权的模型，把手头的资料整理成可继续修改的文档。

## 产品目标

- 用户可以在同一项目中持续工作，隔天找回会话、参考资料和正式成果。
- 长任务可以跨越一次页面访问。用户能看到进度、停止任务，并区分已经保存的成果与尚在生成的回复。
- 管理员可以限制每个人能使用的模型和额度，并根据运行记录排查问题。用户的私人内容按归属控制访问。

## 当前功能范围

| 使用者 | 可以完成的工作 |
| --- | --- |
| 普通用户 | 登录、管理个人会话和项目，配置个人智能体，选择模型与本次任务使用的资料。 |
| 文档作者 | 上传 TXT 或 Markdown，得到文字回复或正式 Markdown 文档，预览、下载并基于指定版本续改。 |
| 任务提交者 | 查看流式回复、队列、用量和资料处理状态，按任务状态暂停、继续、重试或取消。 |
| 管理员 | 管理账号、模型访问和个人预算，查看任务运行诊断。 |

## 首版边界

首版聚焦单部署实例的个人文档工作。跨用户分享、内部市场、外部应用和 IM 机器人接入、多智能体协作，以及视频、表格和演示文稿创作属于首版范围之外。

工作台通过成果卡片打开指定版本。2026-11-20 取消自然语言打开预览的需求，人工审批推迟到出现具体待批准操作时再接入。

## 试用验收范围

已用受控模型验证资料解析、生成文档、关闭页面后找回、下载和基于旧版续改。ECS 单人演练使用真实模型完成文本任务。两位使用者用获准的真实资料跨日找回和续改，以及长会话压缩后的真实模型质量，仍需业务验收。
