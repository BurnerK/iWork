# #18 独立成果版本续改契约

本地实现及确定性验收完成，见 [验证记录](validation/issue18-versions.md)。

在当前会话的正式文档区，用户可切换查看自己的全部版本，选择“基于此版本修改”，提交明确修改要求。任务锁定 baseVersionId；切换个人会话只引用版本，不复制另一会话的消息、SDK 快照或权限。选择来源后为 DOCUMENT 模式，清除选择可新建成果。

版本属于独立成果；来源版本可以是旧版。并发提交均追加新版本：完成事务锁成果行，分配单调版本号，并记录来源版本。编号表示保存顺序，不暗示都基于最新版本。无需覆盖、分享、协作编辑或分支对比。

旧版内容和标题均按版本保持不变。当前版本读取工具只能读取本任务已授权的唯一来源版本，最多每次 12000 字符，不接受其他成果标识或路径。生成仍先准备正文，完成事务才发布；同一任务最多一个版本。取消、保存失败和迟到结果均不能覆盖旧版。

完整版本、来源关系及正式文件参与协调备份；工作区清理不影响引用。实际隔天和真实摘要质量留到 #26，本票只验证真实持久化/重启及可控模型组合行为。
