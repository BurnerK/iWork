# #22 个人智能体配置契约

首版配置只有名称（1–120字符）、指令（1–4000字符）和模型。归属当前用户，不包含凭据、Skill/MCP、共享、子智能体或可编辑工具清单。创建/修改必须重新验证当前身份与模型授权；读取/修改按owner过滤，管理员没有私人配置阅读特权。GET /api/agents 按更新时间分页，每页20；POST创建，GET/PUT /api/agents/{id}读取/修改。

任务在 modelId（直接使用模型）和 agentId（使用个人智能体）之间二选一，不能同时传。agentId进入幂等指纹；相同旧请求即使配置已编辑仍返回原任务，不启动新执行。配置编辑和任务提交共享当前身份行锁，受理事务保存模型、智能体名称和指令快照。运行中的任务使用快照；新任务使用最新配置和实际授权。历史直接模型请求指纹保持兼容。

Harness每任务独立构建，固定平台提示后加入本次快照指令；不从会话快照恢复旧配置、旧工具或权限。配置指令字节计入上下文预算；每次模型调用继续经过实际身份/授权/额度/尝试次数边界。资料仍需本次任务明确选择，实际读取时校验当前身份与资料所有者。使用者、任务所有者与预算承担者始终相同。

V11新增personal_agents及任务配置快照字段。旧任务为空配置，保留原行为。输入与配置私有内容只在用户自身API展示；不提供管理员私人内容入口。任务列表展示提交时智能体名称以区分后来编辑的配置。

界面增加“我的智能体”管理入口；会话“使用方式”可选择直接模型或自己的智能体。模型直用入口保留，配置选择支持继续加载分页。编辑失败保留表单，提交结果未知的任务保留agentId/requestId，重开重试不重复执行。表单使用已有DESIGN tokens与原生label/required/maxlength，不新增视觉规范。
